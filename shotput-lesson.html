การทุ่มน้ำหนัก

เรียนรู้หลักการ ทักษะ กติกา และความปลอดภัย ก่อนฝึกปฏิบัติจริง

1. ความรู้เบื้องต้นเกี่ยวกับการทุ่มน้ำหนัก

การทุ่มน้ำหนักเป็นกรีฑาประเภทลาน ผู้แข่งขันใช้มือข้างเดียวทุ่มลูกน้ำหนักจากบริเวณใกล้คอหรือไหล่ออกไปให้ได้ระยะทางไกล โดยต้องปฏิบัติภายในวงทุ่มและตามกติกา

  • ใช้มือข้างเดียวในการทุ่ม
  • วางลูกน้ำหนักบริเวณโคนนิ้ว ไม่วางลึกกลางฝ่ามือ
  • ลูกน้ำหนักอยู่ใกล้บริเวณคอหรือไหล่
  • ใช้แรงจาก ขา → สะโพก → ลำตัว → ไหล่ → แขน → มือ
  • รักษาสมดุลและคำนึงถึงความปลอดภัย
คำสำคัญ: “ทุ่ม” ไม่ใช่ “ขว้าง”

2. ทักษะพื้นฐานและขั้นตอนการทุ่มน้ำหนัก

1 จับ
วางลูกน้ำหนักบริเวณโคนนิ้ว นิ้วช่วยรองรับและควบคุม
2 วาง
นำลูกน้ำหนักเข้าใกล้คอหรือไหล่ ไม่ลดลงมาเหวี่ยงขว้าง
3 เตรียม
ยืนมั่นคง งอเข่าเล็กน้อย เตรียมใช้แรงจากขาและลำตัว
4 ทุ่ม
ส่งแรง ขา → สะโพก → ลำตัว → ไหล่ → แขน → มือ และดันลูกออกต่อเนื่อง
5 ทรงตัว
ควบคุมร่างกายหลังปล่อย ไม่ออกจากวงอย่างผิดกติกา

จำง่าย: จับ → วาง → เตรียม → ทุ่ม → ทรงตัว

3. หลักการส่งแรงและข้อผิดพลาดที่พบบ่อย

การทุ่มที่มีประสิทธิภาพเกิดจากการประสานงานของร่างกาย ไม่ใช่แรงแขนเพียงอย่างเดียว

  • วางลูกกลางฝ่ามือมากเกินไป: ฝึกวางบริเวณโคนนิ้ว
  • ลูกออกห่างจากคอก่อนทุ่ม: ฝึกตำแหน่งการวางให้ถูกต้อง
  • เหวี่ยงเหมือนการขว้าง: เน้นการดัน/ทุ่มจากบริเวณคอหรือไหล่
  • ใช้แรงแขนอย่างเดียว: ฝึกส่งแรงจากขาและสะโพก
  • รีบใช้แรงจนเสียสมดุล: ฝึกช้าให้ลำดับถูกต้องก่อน
Coach Tips: แรงเริ่มจากขา ส่งผ่านลำตัว แล้วจึงถ่ายทอดไปยังแขนและลูกน้ำหนัก

4. กติกาพื้นฐาน

  • ทำการทุ่มจากภายในวงทุ่ม
  • ใช้มือข้างเดียว และลูกน้ำหนักอยู่ใกล้คอหรือไหล่ก่อนส่งออก
  • ใช้ลักษณะการทุ่ม/ดัน ไม่ใช่การเหวี่ยงขว้าง
  • ลูกน้ำหนักต้องตกภายในเขตที่กำหนด
  • ไม่สัมผัสบริเวณต้องห้ามตามกติกาขณะทุ่ม
  • รอให้ลูกตกก่อนออกจากวงตามบริเวณที่กติกากำหนด

หลักสำคัญ: ทุ่มไกล + ทักษะถูกต้อง + อยู่ในกติกา = ผลงานที่มีคุณภาพ

5. ความปลอดภัย สรุป และสะท้อนคิด

  • ทุ่มเฉพาะเมื่อได้รับสัญญาณจากครู
  • พื้นที่ด้านหน้าต้องปลอดคน
  • ผู้รอฝึกอยู่ในบริเวณปลอดภัย
  • ห้ามโยนหรือทุ่มลูกน้ำหนักเล่น
  • ไม่เข้าเก็บอุปกรณ์จนกว่าครูจะให้สัญญาณ
  • ใช้อุปกรณ์เหมาะกับวัยและตรวจพื้นที่ก่อนฝึก

คำถามสะท้อนคิด

  1. เพราะเหตุใดจึงไม่ควรใช้แรงแขนเพียงอย่างเดียว?
  2. การ “ทุ่ม” แตกต่างจากการ “ขว้าง” อย่างไร?
  3. ถ้าลูกตกนอกเขต แม้ทุ่มได้ไกล ผลควรเป็นอย่างไร?
  4. ทำไมต้องรอสัญญาณครูก่อนเข้าเก็บลูกน้ำหนัก?
  5. ผู้เริ่มต้นควรเน้นการใช้แรงมาก หรือทักษะและความปลอดภัยก่อน เพราะเหตุใด?
